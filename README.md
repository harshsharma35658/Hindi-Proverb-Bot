# Hindi Proverb Bot

A rule-based Python chatbot that gives Hindi proverbs/Kahawat based on user topics. 
Type any topic like "mehnat", "dosti", "time" and get relevant Hindi sayings instantly.

## Features
- Rule-based system using Python dictionaries
- Topic-based Hindi proverb matching
- Simple command-line interface
- Covers common topics: mehnat, dosti, samay, gyan, etc
- Easy to extend with new topics and proverbs
- No external API or LLM required - runs offline

## Tech Stack
- **Language**: Python 3
- **Concepts**: Dictionary, Functions, String matching, CLI

## How to Run
1. Make sure Python is installed
2. Run the file: `python bot.py`
3. Enter a topic when prompted
4. Type `exit` to quit
